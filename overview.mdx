TLDR, Lumalytics is a tool for analyzing Luma CSVs. It ingests all your event CSVs and is able to create connections and deeper
insights than what is typically available in your default Luma Calendar.

### Key Features:
- RSVP vs Attendance
- Total Event count
- Returning vs New Attendees
- Tracks all reviews
- [Custom Data fields (more about this here)](/attendees#how-custom-data-is-processed-and-stored)
- Average check-in time
